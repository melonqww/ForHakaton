# Система автоматического анализа обращений граждан Омской области

Решение для автоматической обработки, фильтрации и приоритизации обращений граждан в Министерство цифрового развития Омской области. Пайплайн адаптирован под работу с большими реестрами (до 400 000 записей) и работает локально, без отправки данных во внешние облачные API.

---

## Архитектура и основные функции

### 1. Двухэтапная фильтрация (ML + Эвристики)
* Для отделения реальных инцидентов от спама, вопросов и благодарностей используется Ridge Classifier на признаках TF-IDF. Скорость классификации на процессоре составляет более 150 000 строк в секунду.
* Модель умеет автоматически дообучаться на входящих размеченных файлах, если в них есть колонка с метками классов.
* Для перехвата скрытых проблем, написанных с иронией (например: "Спасибо за каток на тротуаре, сломал ногу"), используются встроенные лингвистические правила.

### 2. Гео-нормализация и заполнение пропусков
* Названия муниципальных районов сопоставляются с официальным справочником Омской области через нечеткий поиск (библиотека rapidfuzz). Результаты поиска кэшируются, что снижает время повторных обращений до O(1).
* Если в строке отсутствует название населенного пункта, алгоритм пытается извлечь его из текста обращения с помощью регулярных выражений. Если упоминаний нет, подставляется административный центр текущего района.

### 3. Ранжирование и суммаризация
* Каждому инциденту присваивается ранг критичности от 1 до 5 на основе ключевых слов (5 — чрезвычайные ситуации и угрозы жизни, 1 — минимальная важность или благодарность).
* Краткая суть обращения (саммари) выделяется с помощью оптимизированного алгоритма TextRank на чистом Python, который очищает текст от приветствий и шумовых фраз.
* Для топ-районов предусмотрена генерация сводных отчетов с помощью локальной LLM (модель Qwen 2.5:0.5b через Ollama).

### 4. Оптимизация памяти при экспорте
* Чтение Excel-файлов выполняется с помощью Rust-движка calamine. Система считывает только 7 колонок, необходимых для анализа, игнорируя остальные столбцы.
* Запись результатов ведется в стриминговом режиме (openpyxl в режиме write_only). Это позволяет обрабатывать файлы любого объема (включая реестры на 400 000 строк) без перегрузки оперативной памяти.
* Итоговый отчет содержит выпадающие списки категорий для ручной корректировки, тепловую карту критичности и вкладку со сводной аналитикой по районам.

## Структура проекта

* app.py — веб-интерфейс на Streamlit для загрузки файлов и просмотра аналитики.
* main.py — консольный запуск пайплайна с выводом метрик классификации (Accuracy, Precision, Recall, F1).
* src/ — исходный код модулей:
  * src/pipeline.py — координация этапов обработки и автозаполнение гео-данных.
  * src/classifier.py — бинарный классификатор спама и эвристики сарказма.
  * src/preprocessing.py — очистка текстов от лишних пробелов и нечеткое сопоставление районов.
  * src/summarizer.py — извлечение сути (TextRank), расчет критичности и интеграция с Ollama.
  * src/exporter.py — экспорт данных в Excel с форматированием.
  * src/config.py — справочники районов, категорий и ключевые слова критичности.
  * src/ollama_helper.py — проверка статуса и автоматическое скачивание Ollama/моделей в фоне.

## Запуск проекта

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск веб-панели
```bash
streamlit run app.py
```

### Запуск в консольном режиме (CLI)
```bash
python main.py --input ваш_файл.xlsx --output результат.xlsx
```
Дополнительные флаги:
* `--use-llm` — использовать локальную LLM Ollama для суммаризации всех строк.
* `--retrain` — принудительно переобучить классификатор на разметке входного файла.

---

## Работа с локальной LLM (Ollama)

По умолчанию пайплайн работает полностью автономно на CPU-friendly алгоритмах (TextRank для саммаризации). Ollama не является обязательной для запуска.

Если в Streamlit включить опцию LLM-суммаризации, приложение автоматически проверит статус Ollama. Если сервис не установлен или не запущен, интерфейс предложит скачать установщик в папку проекта, а при отсутствии модели Qwen 2.5:0.5b скачает её в фоновом режиме.

## Офлайн-запуск одним файлом

Windows:

```bat
Windows\Запуск.bat
```

Linux:

```bash
chmod +x Linux/run.sh
./Linux/run.sh
```

Скрипты запуска не используют интернет: они не скачивают Python, пакеты, Ollama или LLM-модель. Для полностью офлайн-запуска зависимости должны быть заранее установлены в Python/.venv/portable Python или лежать локально в папке `offline_packages`/`wheels`.
