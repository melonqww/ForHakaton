Быстрый старт

Windows:
Запуск.bat

Linux / macOS
run.sh


Откроется браузер с веб-интерфейсом. Загрузите `.xlsx`-файл и нажмите «Начать обработку»

Для запуска в консольном режиме (без UI):

python main.py --input ваш_файл.xlsx --output результат.xlsx

Структура проекта


app.py               Streamlit веб-интерфейс
main.py              консольный запуск + метрики классификации
src/
  pipeline.py        основной конвейер обработки данных
  classifier.py      бинарный классификатор (TF-IDF + RidgeClassifier)
  summarizer.py      суммаризация TextRank и ранг критичности 1–5
  preprocessing.py   очистка текста, нормализация районов (rapidfuzz)
  exporter.py        экспорт в Excel с форматированием (openpyxl)
  config.py          справочники районов Омской области и индексы колонок
  ollama_helper.py   работа с локальной LLM Ollama (опционально)
Windows/             bat-скрипт для Windows
Linux/               sh-скрипт для Linux


Что делает система

1 Классификация - отделяет реальные проблемы от спама благодарностей и вопросов (TF-IDF + RidgeClassifier обучается на входных данных автоматически)
2 Гео-нормализация - приводит названия районов к единому справочнику Омской области через нечёткий поиск (rapidfuzz)
3 Ранжирование критичности - присваивает ранг 1–5 по ключевым словам (1 — минимальный 5 — ЧП/угроза жизни)
4 Суммаризация - извлекает суть обращения (по умолчанию TextRank опционально — Qwen2.5:0.5b через Ollama)
5 Excel-отчёт - сохраняет результат с цветовой тепловой картой критичности выпадающими списками категорий и листом сводной аналитики

Зависимости

pip install -r requirements.txt


Для использования LLM-суммаризации дополнительно нужна Ollama с моделью qwen2.5:0.5b. Если Ollama не установлена, интерфейс предложит скачать её автоматически. Без Ollama система работает в полном объёме — только без LLM-суммаризации

Формат входного файла

Ожидается `xlsx` с колонками в стандартном формате реестра Минцифры (индексы из `src/config.py`): дата создания, дата закрытия, группа тем, тема, муниципалитет, населённый пункт, текст обращения
